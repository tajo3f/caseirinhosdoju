# Caseirinhos do Ju V19 — Cabeçalho mobile

Base: V18.2 FULL. Menu à esquerda, logo oficial centralizada e carrinho à direita; cabeçalho continua visível durante a rolagem. Menu acessível e fechado ao clicar fora, abrir carrinho, usar Escape ou voltar ao desktop; barras e atalhos consideram Safe Area iOS. Movimento suave, com opção de redução para acessibilidade. Catálogo, preços, fotos, horários, WhatsApp, SEO e editor visual foram preservados.

Para editar pelo Gemini/Codex: `GEMINI.md`, `docs/DESIGN-SYSTEM-V19.md`. Para alterar preços: `data/precos.json`. Build Vercel: `node scripts/build.mjs`, output `dist`, framework Other, raiz `/`. A atualização do projeto de produção requer commit no GitHub; nenhum arquivo deste pacote foi publicado automaticamente.
