# QA V18.2 — fotos e ícones

Conferência da versão baseada na V18.1 FULL: 13 produtos preservados, preços definitivos preservados, páginas individuais geradas, galeria de bandejas, ícones fornecidos pelo cliente, responsividade por media queries e cache versionado. Site estático em Node.js sem dependências npm externas e sem Python no build.

## Testes executados

- `npm test` e `npm run build` — build Node, dados de produtos, preços, rotas internas, JSON-LD, cache e datas de disponibilidade.
- `tests/site-v18-2.test.cjs` — checa nova foto, recortes, ícones, notas de apresentação, preços e caminhos em `dist/`.
- Parser CSS: nenhum erro de sintaxe; arquivos WebP/PNG novos foram abertos e verificados.
- Arquivos originais de referência preservados em `assets/source/`, excluídos do site publicado.
- Teste de pacote GITHUB descompactado em pasta limpa executado antes da entrega.

**Limitação do ambiente de visualização:** a navegação local do Chromium foi bloqueada com `ERR_BLOCKED_BY_ADMINISTRATOR` nos tamanhos 390, 768 e 1440 px. Portanto, a revisão visual automatizada no navegador não foi concluída. Confira a visualização prévia da Vercel antes de colocar em produção.

**Limitação operacional:** o site não possui validação de estoque ou agenda no servidor; a disponibilidade é conferida no cliente e a confirmação final é feita com o Ju pelo WhatsApp.
